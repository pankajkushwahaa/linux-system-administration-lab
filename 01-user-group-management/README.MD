# User and Group Management

## Objective

This lab demonstrates Linux user and group administration using Ubuntu and CentOS.

## Topics Covered

- Display current user
- View user information
- Create users
- Set user passwords
- Create groups
- Add users to groups
- Change primary group
- Delete users and groups

## Environment

- Ubuntu (WSL)
- CentOS (VirtualBox)

## Skills

- Linux
- User Management
- Group Management
- System Administration
- Command Line
