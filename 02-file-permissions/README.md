# File Permissions

## Objective

This lab demonstrates Linux file ownership, permissions, and access control using Ubuntu (WSL) and CentOS. The objective is to understand how Linux secures files and directories through users, groups, and permission bits.

## Topics Covered

- Viewing file permissions
- Changing permissions
- Changing file ownership
- Changing group ownership
- Numeric (Octal) permissions
- Symbolic permissions
- Default permissions (umask)

## Environment

- Ubuntu (WSL)
- CentOS (VirtualBox)
