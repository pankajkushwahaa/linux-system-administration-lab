# Notes

## Permission Types

r = Read (4)

w = Write (2)

x = Execute (1)

---

## Numeric Permissions

7 = rwx

6 = rw-

5 = r-x

4 = r--

0 = ---

---

## Permission Structure

Example:

-rwxr-xr--

Owner : rwx

Group : r-x

Others : r--

---

## Ownership

Every file has:

- Owner
- Group
- Others

---

## Commands

chmod → Change permissions

chown → Change owner

chgrp → Change group

umask → Display default permission mask
