# Notes

## APT

Advanced Package Tool used in Debian and Ubuntu.

Commands:

- apt update
- apt install
- apt remove
- apt upgrade

---

## DNF

Package manager used in CentOS Stream, Rocky Linux and Fedora.

Commands:

- dnf install
- dnf remove
- dnf update

---

## Repository

A server containing software packages.

---

## Package Cache

Stores downloaded package files locally.

---

## Common Interview Questions

Q. Difference between apt update and apt upgrade?

Answer:

apt update refreshes the package list.

apt upgrade installs available updates.
