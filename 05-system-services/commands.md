## Check Service Status

### Command

```bash
systemctl status ssh
```

### Explanation

Displays whether the SSH service is active, inactive, or failed.

### Verification

Check for:

- Active (running)
- Loaded
- PID
```


## Start a Service

### Command

```bash
sudo systemctl start ssh
```

### Explanation

Starts the SSH service.
```


## Stop a Service

### Command

```bash
sudo systemctl stop ssh
```

### Explanation

Stops the SSH service.
```


## Restart a Service

### Command

```bash
sudo systemctl restart ssh
```

### Explanation

Restarts the service after configuration changes.
```


## Reload a Service

### Command

```bash
sudo systemctl reload ssh
```

### Explanation

Reloads configuration without fully restarting the service.
```


## Enable Service

### Command

```bash
sudo systemctl enable ssh
```

### Explanation

Starts the service automatically during system boot.
```


## Disable Service

### Command

```bash
sudo systemctl disable ssh
```

### Explanation

Prevents the service from starting automatically at boot.
```


## View Logs

### Command

```bash
journalctl -u ssh
```

### Explanation

Displays logs generated by the SSH service.
```


## List Active Services

### Command

```bash
systemctl list-units --type=service
```

### Explanation

Displays all currently active services.
```


## List Failed Services

### Command

```bash
systemctl --failed
```

### Explanation

Shows services that have failed.
```
