# System Services Management

## Objective

This lab demonstrates how to manage Linux services using `systemctl`. It includes starting, stopping, restarting, enabling, disabling, checking service status, and viewing logs for system services.

## Topics Covered

- Understanding systemd
- Checking service status
- Starting and stopping services
- Restarting services
- Enabling services at boot
- Disabling services
- Viewing service logs
- Listing active services

## Environment

- Ubuntu (WSL)
- CentOS (VirtualBox)

## Services Used

- SSH
- Apache2 / httpd
- Nginx
- Samba
