# Process Management

## Objective

This lab demonstrates Linux process management and monitoring using Ubuntu (WSL) and CentOS. It covers viewing running processes, monitoring system resources, controlling processes, and managing job execution.

## Topics Covered

- Viewing running processes
- Monitoring CPU and memory usage
- Background and foreground jobs
- Killing processes
- Process priorities
- Process tree

## Environment

- Ubuntu (WSL)
- CentOS (VirtualBox)

- Linux
- Process Management
- System Monitoring
